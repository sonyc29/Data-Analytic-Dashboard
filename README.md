# Swiggy-Data Analytics (Interactive Dashboard creation using Power BI)
## Project Objective
The objective of this project is to analyze the Swiggy food delivery dataset to gain insights into customer ordering behavior, restaurant performance, and delivery efficiency. Using Python, SQL, and Power BI, the project focuses on transforming raw data into interactive visualizations and key performance indicators (KPIs) to support data-driven decision-making.

## Dataset used
- <a href="https://github.com/sonyc29/Data-Analytic-Dashboard/blob/main/swiggy_cleaned.csv">Dataset</a>

### Tools & Technologies
- Python (Pandas, NumPy)
- SQL (Data extraction & transformation)
- Power BI (Dashboard & reporting)
- Excel / CSV datasets
- Git & GitHub

### Features
- Data cleaning and preprocessing
- KPI tracking and performance metrics
- Interactive charts and filters
- Trend and comparative analysis
- User-friendly dashboard layout

## Conclusion

This project analyzes the Swiggy food delivery dataset to uncover key insights into customer behavior, restaurant performance, and delivery operations. The analysis shows that order volumes peak during meal hours, with customers preferring popular cuisines and highly rated restaurants. Delivery time and distance significantly impact customer satisfaction, while discounts and offers positively influence order frequency. City-wise and restaurant-level analysis highlights high-demand regions and top-performing partners. Overall, the project demonstrates how data analytics and interactive dashboards can convert raw data into actionable insights, enabling data-driven decisions to improve operational efficiency and customer experience.
